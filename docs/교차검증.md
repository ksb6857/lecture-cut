# 3.5단계 — 전사 교차검증 (위스퍼 × CTC)

위스퍼 한 벌만 믿으면 두 가지를 못 본다. **없던 말을 지어내는 것**과
**있던 말을 통째로 흘리는 것**이다. 둘 다 임계값으로는 못 거른다.
환각은 높은 confidence 로 나오기 때문이다(`no_speech_prob` 는 낮고
`avg_logprob` 는 높다).

그래서 구조가 다른 모델을 하나 더 돌려 맞춘다.

## 왜 CTC 인가

CTC 모델(`kresnik/wav2vec2-large-xlsr-korean`)은 언어모델 없이 프레임마다
글자를 뱉는다. **소리가 없으면 아무것도 못 내놓는다.** 위스퍼처럼 앞말을 보고
그럴듯한 다음 말을 이어 쓰지 못한다. 그래서 환각 판정에 쓸 수 있다.

정확도는 위스퍼보다 낮다. **자막 문구를 CTC 에서 가져오지 마라.**
소리가 있었는지, 두 모델이 같은 말을 들었는지만 본다.

정확도 높은 두 번째 의견이 필요하면 Cohere Transcribe(2B, Apache 2.0, 한국어
포함) 같은 것이 있지만, 모델 카드가 "무음도 받아쓰려는 경향이 있다"고 밝힌다.
환각 판정 자리에는 못 쓴다.

## 돌리는 법

```
python src/crosscheck_ctc.py work/<이름>.wav work/<이름>_speech.json \
       work/<이름>_ctc.json
python src/compare_transcripts.py work/<이름>_words.json work/<이름>_speech.json \
       work/<이름>_persegment.json work/<이름>_ctc.json \
       work/<이름>_교차검증.md --접두 work/<이름>
python src/fill_missing_words.py work/<이름>_words.json \
       work/<이름>_missing.json work/<이름>_words_full.json
```

110분 강의(발화 덩어리 767개)가 **CPU 로 3.9분**이다. GPU 는 필요 없다.
`transformers` 와 `soundfile` 이 있어야 한다.

`fill_missing_words.py` 를 돌린 뒤에는 **4단계부터 `_words_full.json` 을
words.json 자리에 쓴다.**

## 실측 (원격연수 한 차시, 110.8분)

| | |
|---|---|
| 환각 | 20곳. **그중 19곳이 0.6초 미만 덩어리** |
| 통짜 전사가 흘린 말 | 69개 덩어리 61.3초 |
| 새로 찾은 실패 테이크 | 7곳 35.7초 |
| 뒤집은 판단 | 3건 |

### 흘린 말이 왜 위험한가

컷은 파형 기준이라 흘린 말도 영상에는 남는다. 문제는 **재발화 판정이 그 구간을
못 본다**는 것이다. 「추론 단계를 높이라」는 문장을 세 번 말했는데 통짜 전사에
첫째와 셋째만 있어서, 가운데 테이크가 러프컷에 그대로 남았다.

흘린 것 중 하나는 학습 목표를 마무리하는 문장이었다. 전사에 없으니 "이 문장은
녹화에서 빠졌다, 재녹음이 필요하다"고 잘못 보고했다가 교차검증으로 뒤집었다.

### 환각은 짧은 덩어리에서만 난다

| 발화 덩어리 길이 | 개수 | 환각 |
|---|---|---|
| 0.6초 미만 | 68 | **18 (26.5%)** |
| 0.6~1.0초 | 70 | 0 |
| 1.0~2.0초 | 260 | 0 |
| 2.0초 이상 | 369 | 0 |

그래서 `transcribe_per_segment.py` 가 **0.6초 미만 덩어리를 아예 전사하지
않는다**(`--최소길이` 로 바꾼다). 컷은 파형 기준이므로 안 적어도 영상에서
사라지지 않는다.

### 용어집으로 환각을 막으려 하지 마라

`initial_prompt` 용어집을 강의에 맞게 바꾸면 **전문용어 오전사는 확실히 준다.**
실측에서 9종 중 7종이 사라졌다. 「오드코딩」이 「바이브 코딩」으로,
「라바스크립트」가 「자바스크립트」로, 「베스트 모드」가 「게스트 모드」로 바로잡혔다.

그런데 **환각 총량은 안 준다.** 그 덩어리에서 다른 말이 나올 뿐이다.

| 환각 문구 | 다른 강의 용어집 | 이 강의 용어집 |
|---|---|---|
| 「삽화, 그림체…」 (용어집 문장 그대로) | 8 | 0 |
| 「자막 제공 및 …광고를 포함」 | 4 | 7 |
| 「시청해주셔서 감사합니다」 | 2 | 4 |
| 「다음 영상에서 만나요」 | 2 | 6 |
| 합계 | **16** | **17** |

용어집은 환각이 무슨 말을 하는지만 바꾼다. 일어나는지 아닌지는 길이가 정한다.

## 대본이 있으면

강의 대본이 있어도 **"대본과 다르게 말했다"를 지적으로 올리지 마라.**
말하는 사람은 현장에서 더 나은 표현으로 바꿔 말하고 설명을 덧붙인다.
실측에서 대본 정렬률이 낭독 구간 79%, 시연 구간 40%였다.

대본으로 볼 것은 두 가지다.

- **같은 문장을 두 번 이상 읽었는가** — 재발화 판정의 정답지가 된다.
  실측에서 자동 삭제 91건 중 50건을 대본 정렬이 같이 지목했고, 반대한 6건은
  전부 정렬 쪽 오매칭이었다.
- **화면에 인쇄된 글자와 말이 다른가** — 슬라이드와 프롬프트 상자의 문구만
  뽑아 맞춘다. 실측에서 화면 문구 19개 중 하나가 어긋났다(화면 `130%`,
  말 "1.5배").
